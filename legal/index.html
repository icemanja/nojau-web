Privacidad

Responsable
Javier Doblas Martín · jdoblas [arroba] nojau.es
Qué datos
Solo los que tú facilites al escribir por correo electrónico: nombre, dirección de correo y contenido del mensaje. Esta web no tiene formularios ni áreas de usuario.
Para qué
Responder a tu consulta y, en su caso, gestionar una posible colaboración profesional.

Tu consentimiento al escribir y, si la conversación avanza, la aplicación de medidas precontractuales a petición tuya.

Destinatarios
No se ceden datos a terceros salvo obligación legal. El correo electrónico lo gestiona el proveedor de correo del dominio en calidad de encargado del tratamiento.

Puedes solicitar el acceso, la rectificación, la supresión, la oposición, la limitación o la portabilidad de tus datos escribiendo a la dirección de contacto. Si consideras que no se han atendido correctamente, puedes reclamar ante la Agencia Española de Protección de Datos (www.aepd.es).

Alojamiento y estadísticas

La web está alojada en GitHub Pages (GitHub, Inc.). Como cualquier servidor web, GitHub puede registrar la dirección IP de los visitantes por motivos de seguridad, según su propia política de privacidad.

Para saber cuántas personas visitan la web se usa GoatCounter, un servicio de estadísticas que no usa cookies ni guarda datos personales identificables: solo recoge datos agregados como la página visitada, la web de procedencia, el navegador o el tamaño de pantalla.

Cookies

Esta web no utiliza cookies propias ni de terceros. Las fuentes tipográficas se sirven desde la propia web, sin conexiones a servicios externos de tipografía.
